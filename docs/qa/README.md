# Evidencia de QA

Los informes, métricas y comparadores HTML se versionan. Las capturas se conservan localmente en `docs/qa/<sesión>/screenshots/`; `.gitignore` excluye esas carpetas del repositorio.

Los comparadores y enlaces PNG requieren las capturas locales de la sesión correspondiente. No se incluyen al clonar el repositorio.

Las imágenes que utiliza el sitio, como `public/assets/projects/poultry-home.png` y `public/assets/projects/nutry-home.png`, siguen versionadas porque son necesarias para el despliegue.
